## Условие задачи

Садовод-робот сажает семена в лунки. Лунка считается "идеальной" для посадки, если все три измеренных параметра кислотности почвы (A, B, C) кратны трем. Запишите условие для "идеальной" лунки.

## 1. Алгоритм и блок-схема

Алгоритм

**Начало**

1. **Объявить переменные:**

a, b, c — параметры кислотности (целые).

ideal — результат проверки (целое: 0 или 1).

2. **Ввести с клавиатуры три числа:**

scanf("%d %d %d", &a, &b, &c)

3. **Проверить условие идеальности:**

ideal = (a % 3 == 0) && (b % 3 == 0) && (c % 3 == 0)

4. **Вывести результат.**
